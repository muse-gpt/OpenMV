# 歌曲解析速查

## 输出字段

| 字段 | 含义 | 使用方式 |
| --- | --- | --- |
| `bpm` | 估计曲速（±1 属正常） | 明显不符时手填，不要改画面迁就 |
| `beatOffsetSeconds` | 第一拍相对音频起点的偏移 | 卡点对齐；不要假设第一拍在 0 秒 |
| `sections[]` | 段落：`kind/start/end/energy/bars` | 段落 → 镜头；可手改 |
| `durationSeconds` | 歌曲长度 | 决定片长上限 |

## 段落判定

- 每小节取「最响 10% 帧」的均值作为小节能量，再按全曲峰值归一。
- 能量 > 0.72 → high（通常副歌）；< 0.45 → low；其余 mid。
- 首段低能量 → `intro`；末段低能量 → `outro`；全曲明显最响且超过中位数 1.35 倍
  的段落会被标成 `chorus`。
- 短于两小节的内部碎段会并回能量更接近的邻居；首尾短段落保留。

## 已知限制

- 只支持 PCM WAV（16/24 bit 整数、32 bit 浮点）。
- 对无鼓点的持续音、自由速度、渐强无段落切换的曲子，段落可能只有一段。
- 不给出调性、和弦、乐器或情绪标签；这些必须由创作者判断。
- 边界按小节对齐，四舍五入到最近的小节；不要用它做毫秒级对齐。
